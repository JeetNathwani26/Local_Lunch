# Design System

## Design Direction

Local Lunch should feel premium, modern, warm, human and editorial.

## Layout

- Strong visual hierarchy
- Generous whitespace
- Clear section rhythm
- Large editorial typography
- Large, purposeful imagery
- Controlled use of rounded surfaces

## Typography

The final font pairing will be selected during visual design work.

Required hierarchy:

- Display
- H1
- H2
- H3
- Body
- Small / Label

## Color

Do not hardcode a final palette until brand guidelines are approved.

Use design tokens so the palette can be changed centrally.

## Spacing

Use a consistent spacing scale rather than per-component arbitrary spacing.

## Motion

Preferred motion language:

- Fade
- Slide
- Image reveal
- Subtle scale
- Hover micro-interaction

Motion must remain subtle and should support comprehension.

## Components

Core reusable components will include:

- Button
- Container
- Section
- Badge
- Typography primitives
- Header
- Footer
- Mobile navigation
- Cards
- Form controls
