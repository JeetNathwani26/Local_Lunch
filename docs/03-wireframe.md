# Local Lunch Wireframe

## Global Structure

Header
→ Page content
→ Footer

## Home

Header
→ Hero
→ Brand Introduction
→ Features
→ How It Works
→ Visual Story
→ Showcase
→ Testimonials
→ Final CTA
→ Footer

### Hero

Purpose: establish the brand immediately.

Content:

- Brand eyebrow
- Main headline
- Supporting statement
- Primary CTA
- Secondary CTA
- Hero visual

### Brand Introduction

Purpose: explain Local Lunch in one clear section.

Content:

- Section label
- Heading
- Short description
- Supporting visual
- Learn-more CTA

### Features

Purpose: communicate major value areas.

Layout:

Three or more responsive feature cards.

### How It Works

Purpose: explain the experience with a simple sequence.

Layout:

01 → 02 → 03 → 04

### Visual Story

Purpose: combine editorial imagery with a stronger brand narrative.

Layout:

Image + narrative content.

### Showcase

Purpose: demonstrate examples, experiences or brand work.

Layout:

Responsive visual cards/grid.

### Testimonials

Purpose: provide social proof when real testimonials are available.

Do not use placeholder testimonials in production.

### Final CTA

Purpose: provide a clear next action before the footer.

## Responsive Wireframe

### Mobile

Single-column flow, compact navigation, stacked CTAs and cards.

### Tablet

Two-column layouts where content benefits from additional width.

### Desktop

Editorial asymmetric compositions, multi-column grids and large visual areas.
