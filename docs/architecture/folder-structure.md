# Folder Structure

## Source

`src/` contains production application code.

## Components

`src/components/common` contains reusable primitives.

`src/components/layout` contains global layout components.

`src/components/sections` contains reusable page sections.

## Pages

`src/pages` contains route-level page components.

## Data

`src/data` contains structured content used by components.

## Hooks

`src/hooks` contains reusable React hooks.

## Lib

`src/lib` contains framework-independent utilities, constants and metadata helpers.

## Styles

`src/styles` contains global CSS, typography and animation rules.

## Documentation

`docs/` is the project specification source of truth.
